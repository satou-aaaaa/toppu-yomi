# 突風よみ（toppu-yomi）

突風の風速（3秒平均）を見て、日本版改良藤田スケール（JEF0〜JEF5）の階級を当てる1日5問の学習ゲーム。正解したら様子から突風の種類（竜巻・ダウンバースト・ガストフロント）も選ぶ。被害の例・竜巻発生確度ナウキャスト・藤田スケールの問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/toppu-yomi/>

- 中身は気象庁の竜巻などの突風のページ（「日本版改良藤田スケール」<https://www.jma.go.jp/jma/kishou/know/toppuu/tornado1-2-2.html>・「竜巻などの激しい突風とは」・「藤田スケール」・「竜巻発生確度ナウキャスト」・「竜巻注意情報」）に書いてあることだけです。
- 問題に出る風速や様子は練習のための例で、本物の突風ではありません。
- このゲームは防災の助言や、公式の情報の代わりではありません。竜巻などの情報は気象庁で確かめてください。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
